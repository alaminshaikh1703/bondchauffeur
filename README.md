# Bond Chauffeur & Luxury Travel - Frontend

Modern, high-performance web application for luxury executive chauffeur services and bespoke New Zealand travel experiences. Built with Next.js 14, React, TypeScript, Tailwind CSS, Framer Motion, and GSAP.

---

## 🌟 Key Features

- **Executive Fleet Showcase**: High-fidelity presentation of luxury vehicles with interactive specifications and hourly/transfer rates.
- **Dynamic Booking Concierge**: Multi-step booking experience for city transfers, hourly hire, airport pickup, and intercity transit.
- **Bespoke NZ Travel Concierge**: Immersive travel experience showcase with curated itineraries and inquiry booking.
- **Fluid Micro-Interactions**: Cinematic hero animations, Lenis smooth scrolling, GSAP scroll triggers, and Framer Motion modal transitions.
- **Fully Responsive**: Crafted with modern luxury aesthetic standards for mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Library**: [React 18](https://react.dev/)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18.17.0 or higher recommended)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/) / [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/alaminshaikh1703/bondchauffeur.git
   cd bondchauffeur
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000).

---

## 📦 Scripts

- `npm run dev`: Starts the Next.js development server on port 3000.
- `npm run build`: Compiles and builds the production-ready application.
- `npm run start`: Runs the production server.
- `npm run lint`: Checks for linting errors across the codebase.
